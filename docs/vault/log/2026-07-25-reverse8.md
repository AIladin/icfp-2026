## 05:00 — semantics first, then the grid

Three consecutive reader rebuilds had failed on guessed turn conventions, so this pass started by
pinning them in `machine.py`: spawn direction is EAST; `d` is CW when BP>0 (west→north), `a` CCW,
`x` always turns (low bit 1 → CW); `]` halves BP; `U` re-faces the man **in the pipe's entry
direction** regardless of arrival. That last one dissolved the whole entry-routing problem — the
pop loop can be entered from any side.

## 05:30 — clean rewrite, 8/8 first run

Regenerated `programs/reverse8.man` from a rewritten `py/reverse8_gen.py` (plain string grid, no
Canvas). Key restructurings against the previous broken file:

- go-gate moved **onto the reader's exit path** — the man's post-round walk *is* the gate
- writer lanes flipped parity so both parity branches merge heading east through one shared `a`
  guard, fixing the n=1 zero-pairs deadlock for free
- n-read pinned to the one row where the n-pipe is nearest (the bug that emitted `n` itself)

8/8, 161,719 sparse. Then two structural cuts, each verified by `lm test` before the next:

`lmr` agrees on every number. Shrink sweep removes nothing — all remaining footprint is the
hand-pack, mostly the 10 pure-I/O rows. Full design and **repack invariants** in

at 20×20, ~82K local. Handed to the packer.

## 06:50 — gate latency was on the critical path

The wake-up chain ran entirely *after* the go token arrived: gate first, then 9 cells of
n-read/BP setup before the first pop, every round. Moving the gate one cell — `r`(go) to
(17,16), still strictly go-nearest at distance 2 — puts the block *before* the chain, so only
6 cells run post-wake. Plus a 1-column entry shift trimming the riser walk. 8/8 both runners,
**avg 195.5 ticks** (was 205), sparse 122,188. Packed at 484 that projects ~126K server.
Second user pack submitted at 484 × 273 = **132K** (`e21c02cc`) before this tick cut; the
repack of the same footprint should land ~126K.

## 07:40 — the riser folds into the height slack: 114,925

The user called out the 5 free height rows (width bound at 22, height 17). That unlocked the

and reorder the pipe stack to **pairs, n, odd, go** — legal because `U` skips the empty n row
and odd still pops last. The return path becomes two bottom corridor rows instead of a column;
the two go-`s` cells move to the merge row. `py/reverse21_gen.py`, 8/8 first run, width **21**.

Packed 21×20 with I/O rooms dropped straight into the height slack below the south walls

would *lose* — 484 vs 441). Submitted: **114,925 = 441 × 260.6, 20/20**. Layout:
`programs/reverse-114K-8lane-21wide.man`. Evening total: 148,346 → 114,925 (−22.5%).
