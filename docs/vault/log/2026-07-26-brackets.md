## Hypothesis 2 — pipeline the decode against the stack

One man does read + classify + push/pop + loop, ~35 ticks/char, all serial. Split it across two
men in two rooms and the per-char cost becomes `max(D, C)` instead of `D + C`:

- **D** (decoder): `r` char, `b`, backpack bit tree, land on a digit cell, `s` a signed code to C.
  A, B, BP all free here — the counter is not in this room.
- **C** (stack): `B = S`. `r` the signed code, `X` on its sign: `>0` push (`+++M`), `<0` pop,
  `==0` end of input. Sends a token to N per character.
- **N** (counter): `B = i`. `r`, `X`: `+1` -> `+M` (bump), `0` -> emit 0, `-1` -> `N + s` (emit i+1).
  Owns the output pipe.

The skew problem — which is why the counter is in N and **ticked by C, not by D**: D runs ahead of
C by whatever the pipe holds, so a counter driven by D would name the wrong position. Ticked by C,
`i` is exactly the number of characters C has *finished*, so an offence at character p sees `i=p-1`
and `emit i+1` is right for both the mismatch cases and the unclosed-openers case (offence `n+1`
with `i=n`). Three signals on one pipe, resolved by one `X`.

### H3 — the counter room merges into the decoder with `Y`

**Claim**: the pipeline needs *three* logic rooms, not two, because the decoder cannot hold `i` in
`B` and still run `M 5 W }` — but `Y` puts the counter man and the decoder man in the **same** room,
so the box stays at four rooms (I, M, C, O) and four pipes (I->M, M->C, C->M, M->O).

Reasoning:

- In the stack room `B = S`, so the only ops usable on `A` are `N X b ] x d a m r s` — no constants,
  no `-`. Classification therefore cannot live there (this is the settled result).
- In the decoder, `M 5 W }` gives `t = c >> 5` in four cells and `b x ] x` gives `(`/opener/closer in
  four more, so classification is **8 cells with 2 branch points** instead of the shipped design's
  12 cells with 4. But `M` destroys `B`, so `i` cannot be in the decoder's `B`.
- `Y` copies a man; the two copies keep separate registers but share the room and its pipes. So the
  counter man (`B = i`, reads C->M, writes M->O) and the decoder man (`A`,`B`,`BP` all free, reads
  I->M, writes M->C) cohabit one room.

**Verdict polarity is flipped from the note** so that the pop's own remainder *is* the verdict:
`0` = ok, `>0` = emit `i`, `<0` = emit `0`. A matching pop leaves remainder 0 and a mismatching pop
leaves 1 or 2 (floored `/` with `B = 3` gives a non-negative remainder), so the pop ends `... W X s`
with no constant load on either arm.

With one seed verdict sent by C before its loop, `i` = number of ok verdicts read, and an offence at
character `j` is read when `i = j`, so the emit is plain `W s H` — no `+1`.

### Findings 3 — logic settled further, layout still the blocker

- **`B = i` in the decoder is impossible.** `M 5 W }` opens with `M`, which overwrites `B`. The
  pipeline is therefore *four* logic rooms (I, D, C, N, O) unless a `Y` puts the counter man in the
  decoder's room. [[Pipeline the decoder against the stack]] corrected in place.
- **The chain needs no gate.** `I -> D -> C -> N -> O` gives every room exactly one pipe each way
  (no nearest-pipe ambiguity) and D never blocks, so the per-character cost is `max(D, C, N)` with
  no round-trip latency. Cost: D does not learn about an offence, so C must drain rather than halt,
  and an early-failing case pays a full `n` decodes.

  [[Re-test a backpack bit instead of branching twice]] — `b x`, then `]` on one arm and `] ] ]` on

## Round 3 — the pipeline is built and green

### Two findings that unblocked it

**H1 is only refuted for `B = 0`.** The old exhaustive chain search started from
`A = c, B = 0`. Room D can pin `B` to a constant for free (nothing in its loop touches `B`),
and from `A = c, B = 5` there **is** a branch-free chain — `py/brackets_chain2.py` finds

```
~ * } / ~ -
```

which maps `( [ {` to `+1 +2 +3` and `) ] }` to `-1 -2 -3` in six cells with **no backpack and no
`x`**. Depth 5 is exhausted for k in {0,1,2,3,4,5,32}; 6 is minimal. That deletes the entire
classification tree and, more importantly, deletes the *branch* — which is what a dozen hand rings
died on. D is now one 16-cell ring with `d` as its only turn.

**Base 4, not base 3, for the stack.** With digits 1,2,3 and base 3, a `}` popped off an empty
stack leaves `-3`, which *is* divisible by 3 — a false accept that forces a separate `W X`
empty-stack test. In base 4 no digit in 1..3 divides 4, so underflow always leaves a non-zero
remainder and falls out of the same arithmetic. That removes two cells and one branch point, and
lets both pop and push end at **one shared `s`**: the remainder *is* the verdict.

### The five rooms

`py/brackets_gen10.py`, handoff at `programs/brackets-v10-handoff.man`.

| room | job | ring |
| --- | --- | --- |
| D | `q d 5 M r ~ * } / ~ - s` | 16 cells |

| N | `r X` then `1 + M` (bump), `1 + s H` (emit i+1), `0 s H` (emit 0) | 12 cells |
